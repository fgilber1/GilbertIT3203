Learning HTTP

The foundation of data communication on the World Wide Web is the HyperText Transfer Protocol. HTTP generally communicates over the Transmission Control Protocol.

HTTP Definition

HyperText Transfer Protocol, also known as HTTP, is defined as a standard application-level protocol that is used for exchanging files on the World Wide Web.

The Role and Purpose of HTTP

HTTP is used as the foundational communication system to transfer data between web browsers (or clients) and web servers on the Internet. Though designed for communication between web servers, HTTP can also be used for other purposes, such as machine-to-machine communication and programmatic access to APIs.

HTTP Requests

HTTP requests are messages that are formatted in the HTTP protocol sent from a client to a server that is capable of responding. Requests can be formed by software, APIs, or libraries within an application such as web browsers and email clients. The syntax starts with the noun (which is data values expressed in the message header, options chosen, and body message values) followed by the verb (HTTP request method used, such as GET or POST) to complete the message.

Components of HTTP Requests

  • Request line: Includes the request method, the resource URL, and the HTTP version used. Plays a critical role in defining the type of request and the target resource.
  • Headers: Metadata fields that provide additional information about the request. Headers may include details such as content type, authentication credentials, and user agent.
  • Body: Used in methods that require data submissionm such as POST and PUT. Contains the transmitted data, which can be in formats such as JSON, XML, or form data.

Request Example

GET /docs/tutorials/linux/shellscripts/howto.html HTTP/1.1
Host: Linode.com
User-Agent: Mozilla/5.0 (Windows; U; Windows NT 6.1; en-US; rv:1.9.1.8) Gecko/20091102 Firefox/3.5.5
Accept: text/html,application/xhtml+xml,
Accept-Language: en-us
Accept-Encoding: gzip,deflate
Accept-Charset: ISO-8859-1,utf-8
Cache-Control: no-cache

HTTP Methods

Methods are used to retrieve, update, delete, or perform other actions on a resource.

HTTP Responses

A HyperText Transfer Protocol Response is sent by a server to a client. The purpose of HTTP Response is to provide the client with resources that were requested, or to inform the client that the action requested was completed. Response will also inform the client if the request had an error occur during processing.

Response Example

HTTP/1.1 200 OK
Date: Mon, 27 Jul 2009 12:28:53 GMT
Server: Apache/2.2.14 (Win32)
Last-Modified: Wed, 22 Jul 2009 19:15:56 GMT
Content-Length: 88
Content-Type: text/html
Connection: Closed
