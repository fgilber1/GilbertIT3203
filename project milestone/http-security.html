HTTP Security

The security of Hypertext Transfer Protocol

HTTPS

Hypertext Transfer Protocol Secure (HTTPS) is the secure version of HTTP. It increases the security of data transfers by using encryption protocols. The protocol in particular that HTTPS uses is the Transport Layer Security (TLS), which secures communication by using an asymmettic public key infrastructure.

The two keys in use:

  • Private key: The key is controlled by the owner of a website, and it is kept private. The key lives on a web server and is used to decrypt information encrypted by the public key.
  • Public key: The key is available to everyone who wants to interact with the server in a secure way. The information that is encrypted by the public key can only be detected by the private key.

Importance of HTTPS

HTTPS prevents websites from having their information broadcast in a way that is easily viewed by anyone looking on the network. Using regular HTTP, the data can easily be found by using free software because the information is broken down into said data. This makes communication over an unsecure medium, such as public WiFi, very vulnerable to being intercepted. In comparison, HTTPS is encrypted when beong used so even if the packets of data are intercepted, the information will not come across plainly.
